# Идея проекта

**Цель**: Разработать CRM-систему для фрилансеров, которая поможет им вести учёт клиентов, задач и оплат.

## Целевая аудитория:
- Фрилансеры, работающие в сфере дизайна, копирайтинга, SMM и др.

## Проблемы, которые решает CRM:
- Трудности в учёте клиентов и задач.
- Проблемы с отслеживанием оплат.
